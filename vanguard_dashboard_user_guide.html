Dashboard Installation & User Guide

Run the environmental trend dashboard directly from its GitHub repository on your Windows computer. Follow this guide to install the required tools, start the application, and explore its data.

On this page 1. Requirements 2. Download the project 3. Start the backend 4. Start the frontend 5. Navigate the dashboard 6. Example investigation 7. Troubleshooting 8. Shut down 9. Quick reference

Before you begin

The dashboard uses a React/Vite frontend and a Python backend. Python runs the backend services and data-processing components. Node.js and npm install and run the frontend. Git downloads the source code from GitHub.

Important: These instructions assume Windows and the common project layout containing backend and frontend folders. If the repository README or package scripts specify different commands, follow the repository's instructions.

1. Install the required software

Python 3.11+

Required to run the FastAPI backend and its data-processing components.

Download Python ↗

Node.js (LTS)

Required to install and run the React frontend. npm is included with Node.js.

Download Node.js ↗

Git

Recommended for cloning the project repository directly from GitHub.

Download Git ↗
Windows tip: During Python installation, select Add Python to PATH. After installing the software, close and reopen Command Prompt or PowerShell.

2. Download the dashboard repository

  1. Open the Be-An-Earth-System-Trend-Detective GitHub repository.
  2. Open Command Prompt or PowerShell.
  3. Run the following command to download the project:
git clone https://github.com/underalpha3412/Be-An-Earth-System-Trend-Detective.git

Enter the downloaded project directory:

cd Be-An-Earth-System-Trend-Detective

The project source code is now available on your computer.

3. Start the backend

The backend handles data processing, API requests, calculations, and communication with the frontend.

Open a terminal in the project directory and enter the backend folder:

cd backend

Create a Python virtual environment:

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

Install the required Python packages:

pip install -r requirements.txt

Start the FastAPI server:

uvicorn main:app --reload --port 8000
Backend running
Backend address: http://127.0.0.1:8000
Interactive API documentation: http://127.0.0.1:8000/docs

Note: The command assumes the backend entry point is main.py and that it exposes an application named app. If the repository uses another entry point, use the command specified in its backend README.

4. Start the frontend

Keep the backend terminal open and running. Open a second terminal in the main project directory.

Enter the frontend folder:

cd frontend

Install frontend dependencies:

npm install

Start the React development server:

npm run dev
Frontend ready
Vite usually displays a local address such as http://localhost:5173. Open the exact URL printed in your terminal in Chrome, Edge, or another modern browser.

If the repository uses a different frontend folder or npm scripts, check its package.json and README for the correct commands.

5. How to navigate and use the dashboard

Step 1: Select a locationChoose the city or geographical region you want to investigate using the dashboard's location selector.
Step 2: Set the time periodSelect the historical period you want to study. For example, choose 2015 to 2025 to examine changes over that period.
Step 3: Choose a visualizationSelect an available chart type, such as a line chart, to see how the selected environmental measurements change over time.
Step 4: Examine the resultsStudy the plotted data, look for increasing or decreasing patterns, and compare changes across locations and time periods.
Step 5: Explore AI-powered insightsWhere the AI analysis feature is available, use it to ask questions about the selected data and understand the observed environmental patterns.

7. Common issues and solutions

ProblemWhat to do
python is not recognizedReinstall Python with “Add Python to PATH” enabled, then reopen the terminal.
npm is not recognizedInstall Node.js LTS and restart the terminal.
ModuleNotFoundErrorActivate the virtual environment and install requirements.txt again.
npm install failsCheck your internet connection and Node.js installation.
Frontend cannot connect to backendEnsure the backend is running and the frontend API configuration points to the correct backend URL.
Port already in useStop the other process using that port or configure another available port.

8. How to shut down the dashboard

  1. Return to the backend terminal and press Ctrl + C.
  2. Return to the frontend terminal and press Ctrl + C.
  3. Close the browser tab.

The next time you use the dashboard, start the backend and frontend again. You do not need to reinstall dependencies every time.
